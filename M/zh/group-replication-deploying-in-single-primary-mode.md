Group中的每个MySQL服务器实例都可以运行在独立的物理主机上，这是部署Group Replication的推荐方式。本节介绍如何创建具有三个 MySQL Server 实例的复制组，每个实例在不同的主机上运行。有关在同一台主机上部署多个运行组复制的 MySQL 服务器实例的信息，例如用于测试目的，
请参阅
第 18.2.2 节，“在本地部署组复制” 。
图 18.7 组架构
本教程解释了如何使用组复制插件获取和部署 MySQL 服务器，如何在创建组之前配置每个服务器实例，以及如何使用性能模式监控来验证一切是否正常工作。
