20.1 MySQL文档存储的接口
要将 MySQL 用作文档存储，您可以使用专用组件和一系列支持与 MySQL 服务器通信的客户端来开发基于文档的应用程序。
以下 MySQL 产品支持 X 协议，并使您能够以您选择的语言使用 X DevAPI 来开发与充当文档存储的 MySQL 服务器通信的应用程序：
MySQL Shell（在 JavaScript 和 Python 中提供 X DevAPI 的实现）
连接器/C++
接头/J
连接器/Node.js
连接器/网络
连接器/蟒蛇
MySQL Shell 是支持 JavaScript、Python 或 SQL 模式的 MySQL 的交互式接口。您可以使用 MySQL Shell 来制作应用程序原型、执行查询和更新数据。
