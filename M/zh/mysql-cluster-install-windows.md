第 23.3.2.1 节，“从二进制版本在 Windows 上安装 NDB Cluster”。
也可以使用 Microsoft Visual Studio 在 Windows 上从源代码编译和安装 NDB Cluster。有关更多信息，请参阅第 23.3.2.2 节，“在 Windows 上从源代码编译和安装 NDB Cluster”。
