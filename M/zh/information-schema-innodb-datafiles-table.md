26.4.10 INFORMATION_SCHEMA INNODB_DATAFILES 表
该表为
file-per-table 和通用表空间
INNODB_DATAFILES提供数据文件路径信息。InnoDB
有关相关的使用信息和示例，请参阅
第 15.15.3 节，“InnoDB INFORMATION_SCHEMA 模式对象表”。
笔记
该INFORMATION_SCHEMA
FILES表报告
InnoDB表空间类型的元数据，包括 file-per-table 表空间、通用表空间、系统表空间、全局临时表空间和撤消表空间。
该INNODB_DATAFILES表有以下列：
SPACE
表空间 ID。
PATH
表空间数据文件路径。如果
file-per-table 表
空间是在 MySQL 数据目录之外的位置创建的，则路径值是完全限定的目录路径。否则，路径是相对于数据目录的。
例子
mysql> SELECT * FROM INFORMATION_SCHEMA.INNODB_DATAFILES WHERE SPACE = 57\G
*************************** 1. row ***************************
SPACE: 57
PATH: ./test/t1.ibd
笔记
您必须具有PROCESS
查询此表的权限。
使用INFORMATION_SCHEMA
COLUMNS表或
SHOW COLUMNS语句查看有关此表的列的其他信息，包括数据类型和默认值。
