23.5.26 ndb_select_count — 打印 NDB 表的行数
ndb_select_count打印一个或多个NDB表中的行数。对于单表，结果等同于使用MySQL语句得到的结果。
SELECT COUNT(*) FROM
tbl_name
用法
ndb_select_count [-c connection_string] -ddb_name tbl_name[, tbl_name2[, ...]]下表显示了
