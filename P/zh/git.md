I.1. 通过Git获取源码 #
使用Git你将可以在你的本地机器上创建一份整个代码库的拷贝，这样你将能够离线访问所有历史和分支。这是开发或测试补丁最快也是最灵活的方式。
Git
你将需要一个已安装的Git版本，你可以从https://git-scm.com获取。很多系统已经默认安装了一个最近版本的Git，或者可以从它们的包发布系统中找到。
要开始使用 Git 仓库，请克隆官方镜像：
git clone https://git.postgresql.org/git/postgresql.git
这将把完整的仓库复制到你的本地机器上，因此可能需要
一段时间才能完成，特别是如果你的互联网连接较慢。
文件将放置在你当前目录下的新子目录 postgresql 中。
不管什么时候你希望得到系统的最新更新，cd进入仓库并运行：
git fetch
除了获取源码，Git可以做更多事情。要了解更多，请参考Git手册页，或者访问网站https://git-scm.com。
