DEALLOCATE DESCRIPTORDEALLOCATE DESCRIPTOR — 释放一个 SQL 描述符区域大纲
DEALLOCATE DESCRIPTOR name
描述
DEALLOCATE DESCRIPTOR 释放一个命名的 SQL 描述符区域。
参数name #
要被释放的描述符的名称。它是大小写敏感的。这可以是一个 SQL 标识符或一个主机变量。
示例
EXEC SQL DEALLOCATE DESCRIPTOR mydesc;
兼容性
DEALLOCATE DESCRIPTOR 在 SQL 标准中被规定。
