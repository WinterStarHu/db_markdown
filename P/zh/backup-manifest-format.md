由pg_basebackup生成的备份清单主要用于允许使用
pg_verifybackup验证备份。
但是，其他工具也可以读取备份清单文件并使用其中包含的信息用于其
自己的目的。为此，本章介绍备份清单文件的格式。
备份清单是编码为 UTF-8 的 JSON 文档。
（虽然通常情况下 JSON 文档需要 Unicode，PostgreSQL 允许json
和 jsonb数据类型可使用任何受支持的服务器编码。备份清单
没有类似的例外。）JSON 文档始终是一个对象；此对象中存在的键将放在
下一节中进行介绍。
