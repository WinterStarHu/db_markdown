PostgreSQL 服务器应用程序
这一部分包含PostgreSQL服务器应用程序和支持工具的参考信息。这些命令只在数据库服务器所在的主机上运行才有用。其他工具程序在PostgreSQL 客户端应用程序中列出。

数据库集群的预写式日志pg_walsummary — 打印 WAL 摘要文件的内容postgres — PostgreSQL 数据库服务器上一页 上一级 下一页vacuumdb 起始页 initdb
